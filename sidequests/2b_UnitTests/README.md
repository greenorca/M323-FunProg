# Guide

Die Templatestruktur für ein Sidequest setzt sich aus den folgenden Komponenten zusammen:

| File | Beschreibung | Pflicht |
| --- | --- | ---|
| assets_dev |Dateien welche beim Erstellen der Aufgabe zugedient haben (z.B. drawio od. ähnliche Tools) werden hier für etwaige Anpassungen abgelegt.|N|
| images |Dieser Ordner dient als Ablage für im SideQuest verwendete Bilder|N|
| LB | Beinhaltet die dem Sidequest zugehörige LB Aufgabe | abhängig davon ob es eine klassische LB oder ein Projekt ist / N|
| loesung |In diesem Ordner soll ein Lösungsvorschlag in Form einer README.md, einem Projekt oder beidem ausgelegt werden|Y|
| unterrichtsmaterial | Enthält alles Material was zur Bearbeitung der Aufgabe benötigt wird. Einführungsbeispiele, Code, Skripte usw. Kann den Lernenden zur Verfügung gestellt werden.|N|
| README.md |Diese Datei wird auf dieser Ebene nur im Template zur Erklärung benötigt|N|
| aufgabe.md | Beinhaltet die Aufgabenstellung | Y |
